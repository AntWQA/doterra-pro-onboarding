# dōTERRA Pro onboarding demo

An interactive, mobile-sized prototype of the dōTERRA Pro onboarding journey. It recreates the supplied Figma screens with animated transitions, tappable pagination, swipe navigation, a final dashboard handoff, and native-style fixed chrome.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To test on a phone on the same network, run:

```bash
npm run dev -- --host
```

## Checks

```bash
npm run build
npm run lint
```

## Stack

- React 19
- TypeScript
- Vite
- Motion for React

This repository is a visual prototype, not a production application.
